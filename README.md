# Интернет-магазин

Проект интернет-магазина на Django, разрабатываемый в рамках учебного курса.

## Функциональность

- **Главная страница** - `/catalog/home/`
- **Страница контактов** - `/catalog/contacts/`

## Технологии

- Python 3.13
- Django 5.2
- Git & GitHub

## Установка и запуск

### 1. Клонировать репозиторий
```bash
git clone <https://github.com/ullqp/Django1.git>
```
### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```
### 3. Запуск сервера
```bash
python manage.py runserver
```
